Named adopters: Canonical, Django, Cloudflare, Gatsby, and IBM LoopBack. The framework site claims several hundred projects overall.

Canonical adopted it as the foundation for its technical documentation, both to restructure existing material and to guide new writing. Cloudflare used it as the reference point for information architecture while redesigning its developer documentation, and consulted it when the home for a new page was unclear.
