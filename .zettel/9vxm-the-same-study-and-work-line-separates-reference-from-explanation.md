Reference is what a reader needs while working. Explanation is what a reader turns to while acquiring knowledge. The distinction is the same one that separates a tutorial from a how-to guide, applied to cognition instead of action. See [[c9jx]].

A rough test: boring and unmemorable content, lists and tables, is reference. Content interesting enough to think about at leisure is explanation.

The common failure runs one way. Reference legitimately carries examples, examples are enjoyable to write, and an example grows into an explanation. The reference then reads as a set of digressions, and the explanation, penned inside a reference entry, never gets the room to develop.
