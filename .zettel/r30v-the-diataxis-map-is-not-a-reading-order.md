The four types sit in a two-dimensional relation, not a sequence. No reader is obliged to meet tutorials, then how-to guides, then reference, then explanation. A reader enters wherever the current need points.

The value of the arrangement is that it shapes the material it holds. A reader can tell what a section is for, and a writer can tell what to write and where to put it.

The failure mode is bleed. Adjacent types blur first, and content from one leaks into another. Far enough along, the structure collapses in part or in whole, and the documentation serves nobody.
